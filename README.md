# Home Assistant: The Master Handbook. The Companion

Companion material for the book **"Home Assistant: The Master Handbook. From First Steps to AI-Powered Home Automation"** by Thomas Giehl.

The Companion is a package of text files that you load into your chatbot (Claude, ChatGPT, Gemini or Microsoft Copilot). It knows the structure of the book and the key points of every chapter, and it helps you apply the material to your own home. It does not replace the book text.

## Download

1. Open **Releases** on the right of this page and download the file `ha-master-handbook-companion.zip` of the latest version.
2. Unzip it. The password is at the start of Chapter 0 in the book.
3. Follow the instructions in Chapter 0 or in the file `0_setup_….txt` in your chatbot's folder.

## Contents of the package

| Folder or file | Contents |
|---|---|
| `claude` | the skill as a ZIP file, plus a subfolder `project` as a second route |
| `chatgpt` | an instruction and three knowledge files for a project |
| `gemini` | the Companion in a single file, plus a starter message |
| `copilot` | the same for Copilot and any other chatbot that accepts files |
| `companion_beginner_mistakes.md` | the silly beginner mistakes from Appendix E, to attach when needed |
| `README.txt` | the short version |

First keyword to try: `Companion: Where do I start?`
If the Companion gets too long or asks many questions at once: `Stick to your rules.`
